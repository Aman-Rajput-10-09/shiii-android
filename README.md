# Shiii - Couple Companion AI (Android)

Shiii is a private couple companion AI app featuring an animated chibi AI mediator, secret direct messaging, a 3-way diplomatic group lounge, and real-time relationship briefings.

## Features
- **Couple Pairing**: Secret code-based pairing between Master and Mistress.
- **Interactive Animated Shiii**: Chibi anime companion with lively interactive states (cycling, walking, talking, dancing, crying).
- **Group Lounge**: 3-way conversation space with Shiii acting as an empathetic relationship mediator.
- **Private Direct Chat**: Secure, intimate 1-on-1 direct messaging between partners with live delivery status.
- **Relationship Briefings**: Proactive insights and diplomatic guidance.

## Tech Stack
- **UI**: Jetpack Compose & Material 3
- **Architecture**: MVVM + Clean Architecture
- **Dependency Injection**: Dagger Hilt
- **Networking**: Retrofit 2, OkHttp, Coroutines & Flow
- **Audio**: Custom Voice Playback & MediaPlayer
